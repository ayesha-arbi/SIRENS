# SIRENS FRONTEND INTEGRATION GUIDE: AUTH & ONBOARDING

This guide explains how to connect the frontend (React Native/Web) to the backend interfaces for user registration and onboarding.

## 1. SETUP
Ensure you have the firebase functions SDK installed:
npm install firebase

In your firebase config file, initialize functions:
import { getFunctions } from 'firebase/functions';
const functions = getFunctions();

---

## 2. THE FLOW

### STEP 1: User Sign-Up
After a user successfully signs up via Firebase Auth, call this function immediately to initialize their profile in the 'citizens' collection.

FUNCTION: `initializeUserProfile`
ARGUMENTS: None (uses Auth Context)
RETURNS: { success: boolean, message: string }

### STEP 2: Onboarding Process
As the user moves through the City -> District -> Neighborhood screens, call this function to save their personalized zones.

FUNCTION: `updateOnboardingData`
ARGUMENTS: {
  city: string,
  district: string,
  homeLocation: { area: string, coords: { latitude: number, longitude: number } },
  workLocation: { area: string, coords: { latitude: number, longitude: number } },
  frequentAreas: [ { area: string, coords: { latitude: number, longitude: number } } ],
  onboardingComplete: boolean
}
RETURNS: { success: boolean, message: string }

### STEP 3: Alert Preferences
When the user sets up their notification preferences (Weather, Traffic, etc.).

FUNCTION: `setAlertPreferences`
ARGUMENTS: {
  preferences: {
    weather: boolean,
    traffic: boolean,
    highSeverityOnly: boolean,
    notificationChannel: 'push' | 'email' | 'sms'
  }
}
RETURNS: { success: boolean, message: string }

---

## 3. IMPORTANT NOTES
- AUTHENTICATION: All these functions require the user to be logged in. If they are not, the function will return an 'unauthenticated' error.
- COORDS: All locations must be sent as an object with 'latitude' and 'longitude'.
- DATA STORAGE: Do not write directly to the 'citizens' collection. Always use these functions to ensure data validation and AI trigger synchronization.
